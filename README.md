# ReRead Bookstore

ReRead Bookstore is a PHP and MySQL web application for buying and managing second-hand books. It includes customer registration/login, book browsing, product details, cart pages, checkout flow, order tracking, and a simple admin area for managing products, users, and orders.

## My Contribution

This was a group project. My main responsibility was overseeing and building the frontend parts of the website, especially the HTML structure, CSS styling, page layout, and user-facing interface.

## Features

- Homepage with featured books
- Product catalog and book details pages
- Customer registration and login
- Shopping cart and checkout pages
- Purchase history and order tracking
- Admin dashboard
- Admin product management
- Admin user and order management

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- WAMP Server

## Setup

1. Copy the project folder into your WAMP `www` directory.
2. Create/import the database using `database.sql`.
3. Update `includes/db.php` if your local MySQL username, password, or database name is different.
4. Start WAMP and open `http://localhost/reread_bookstore/`.
